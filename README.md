# Renewable-Asset-Performance-Monitor-(RAPM)
Python based engineering project for renewable asset analytics.
---
![Renewable Asset Dashboard](images/dashboard.png)

## Project Overview
This project demonstrates how Python can be used to monitor renewable energy assets through time-series analysis, KPI reporting, anomaly detection and automated engineering reporting. It simulates the work of an Asset Data Analyst analysing wind, hydro and solar performance data.

---

## Business Problem
Renewable energy operators need to quickly identify underperforming assets, validate operational data and produce consistent performance reports. Manual reporting takes time and can delay engineering decisions.

---

## Solution

This project automates that workflow by:

- Cleaning operational datasets.
- Validating time-series data.
- Calculating engineering KPIs.
- Detecting abnormal performance.
- Producing management-ready reports.
